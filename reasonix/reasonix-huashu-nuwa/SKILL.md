# 女娲 · Skill造人术

基于 [alchaincyf/nuwa-skill](https://github.com/alchaincyf/nuwa-skill) 方法论的移植版。

## 执行流程

### Phase 0: 入口分流
- 用户输入「蒸馏XX」或明确人名 → 直接路径
- 用户输入模糊需求 → 诊断路径

### Phase 0.5: 创建Skill目录
在 `ex/skills/[人名]-perspective/` 下创建 SKILL.md + references/ 子目录

### Phase 1: 多源信息采集（并行Agent Swarm）
6路并行调研：
1. **著作**：书/长文/论文 → 核心论点、自创术语
2. **对话**：播客/访谈/AMA → 即兴反应、立场变化
3. **表达**：社交媒体 → 高频词、句式、争议立场
4. **他者**：他人评价/批评 → 外部视角
5. **决策**：重大决策/转折点 → 决策逻辑
6. **时间线**：完整时间线 → 里程碑、思想转折

硬性要求：存文件、标来源可信度、区分一手/二手/推测、保留矛盾。信息源黑名单：知乎、微信公众号、百度百科。

### Phase 2: 框架提炼
从调研中提取：
- **心智模型**（3-7个）：三重验证 — 跨域复现、生成力、排他性
- **决策启发式**（5-10条）
- **表达DNA**：句式/词汇/节奏/幽默/确定性/引用习惯
- **价值观与反模式**：3-5条价值排序+明确反对的事物
- **智识谱系**：受谁影响→影响了谁
- **诚实边界**：必须写明局限

### Phase 3: Skill构建
按模板组装SKILL.md，含：身份卡、心智模型、决策启发式、表达DNA、时间线、价值观、反模式、智识谱系、诚实边界、调研来源。

### Phase 4: 质量验证
- 已知测试：3个此人公开表态过的问题 → 方向一致？
- 边缘测试：1个此人没讨论过的问题 → 应表现出不确定
- 风格测试：100字 → 有此人的表达特征？

> 女娲不是复制人，是提炼思维框架。捕捉的是 HOW they think，不是 WHAT they said。
