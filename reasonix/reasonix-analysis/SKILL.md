# 分析 Skill · 四维分析引擎

> 四个脑子，一个问题。芒格告诉你哪里会死，塔勒布告诉你尾部风险在哪，费曼告诉你是不是在自欺，纳瓦尔告诉你有没有杠杆。

## 触发条件

当用户说「用分析skill」「四维分析」「四人分析」「分析一下（从多个角度）」「芒格+塔勒布+费曼+纳瓦尔」时激活。

## 执行协议

收到问题后，**同时以四个角色的认知框架分析同一个问题**，每个角色输出独立的一段分析。

### 输出格式

```
━━━ 🧠 芒格 · 逆向+多元思维 ━━━
[芒格视角的分析]

━━━ 🎲 塔勒布 · 风险+反脆弱 ━━━
[塔勒布视角的分析]

━━━ 🔬 费曼 · 科学验证+反自欺 ━━━
[费曼视角的分析]

━━━ ⚡ 纳瓦尔 · 杠杆+自由 ━━━
[纳瓦尔视角的分析]
```

### 各角色分析规则

**芒格视角**：第一问「这件事怎么会让我完蛋」→ 激励结构 → 认知偏误 → Lollapalooza检测 → Too Hard筐判断 → 极短句+干燥幽默，不铺垫。

**塔勒布视角**：第一问「尾部风险是什么」→ 不对称性 → 脆弱/反脆弱 → skin in the game → 遍历性检查 → 格言体+确定性极高+古典引用。

**费曼视角**：第一问「我真的理解这个还是只记住了名字」→ 货物崇拜检测 → 能演示吗 → 选择性看证据了吗 → 口语化+从具体例子开始+主动说不知道。

**纳瓦尔视角**：第一问「有杠杆吗，需要谁的许可」→ 杠杆类型 → 特定知识vs手册化 → 10年后还重要吗 → 在租还是在买 → 金句体+重新定义关键词。

### 分析工作流

1. 理解问题。涉及具体事实 → 先WebSearch
2. 四维并行分析，每个角色独立输出
3. 格式化输出四段分析，每段3-5段不超过300字

### 注意事项
- 不是角色扮演——是用认知框架分析
- 四个分析可能互相矛盾，这是feature
- 涉及具体事件必须先调研真实数据
- 某个角色不适合时主动说明
