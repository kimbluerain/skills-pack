# AI 跨境合规速查工具 — 竞争格局分析（2026年6月）

## 调研背景

Kim（义乌做出口贸易）在考虑做一款面向义乌商户的 AI 跨境合规速查工具：输入商品名+目标国家 → 输出所需认证/法规/关税信息。本节记录 GitHub 和商业市场的竞品情况。

## GitHub 开源项目

搜索 `trade compliance AI` 共 126 个 repo，但**没有产品级别的项目**：

| 项目 | ⭐ | 状态判定 |
|------|----|---------|
| SupplyGraphAI/supplygraph-ai | ⭐5 | AI 报关/HTS分类，刚起步 |
| arJ-V/logistIQ | ⭐3 | 学术demo |
| devandop/global-trade-compliance-ai-assistance | ⭐2 | 原型 |
| mfaktes/hts-classifier | ⭐0 | 空框架 |
| t-krishna/Customs-Compliance-Advisor | ⭐0 | 命令行demo |

**结论：没有竞争对手。** 没有任何一个项目达到产品级别（全部 <10 ⭐）。

## 商业产品

| 公司 | 干什么 | 为什么不适合义乌商户 |
|------|--------|-------------------|
| **Eurora** | AI 跨境合规+关税 | 面向大企业，年费几万起 |
| **Zonos** | 跨境关税计算 | 只算税，不算认证/法规 |
| **Avalara** | 税务合规 | 做美国税，不是出口合规 |
| **阿里巴巴合规中心** | 平台自带 | 只能阿里平台用 |
| **各类报关软件** | 报关单填写 | 传统软件，非AI，操作复杂 |

**结论：没有面向中小义乌商户的 AI 合规产品。**

## 义乌商户的具体痛点（调研推断，非问卷验证）

1. 接到海外订单 → 不知道要什么认证
2. 去问报关行 → 对方说"你先查" → 查半天没结果
3. 硬着头皮发货 → 到海关被扣了 → 赔钱

**高频问题：**
- "这个包卖欧洲要不要 CE？"
- "玩具出口美国要 FDA 什么要求？"
- "电子产品出口日本要 PSE 标志？"
- "HS 编码是什么？关税怎么算？"

## 推荐 MVP 范围

第一步缩小到：
> 输入商品名 → 输出出口目标国家所需认证清单 + 简要说明

先覆盖最常用的 4 个认证体系：
- 欧盟 CE
- 美国 FDA/FCC
- 日本 PSE
- 韩国 KC

## 护城河分析

- **网络效应**：弱 — 用户不需要彼此连接
- **数据飞轮**：强 — 越多人用，法规知识库越全，准确率越高
- **切换成本**：中 — 用户习惯了就懒得换
- **品牌**：弱 — 需要时间积累
- **整体判断**：可以做，护城河靠数据积累和先发优势
